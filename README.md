# Kasepuhan Ciptagelar — Scrollytelling Journey

A filmic, scroll-driven documentary website dedicated to **Kampung Adat Ciptagelar**, an indigenous Sundanese community nestled in the highlands of Mount Halimun, Sukabumi, West Java.

## Stack & Architecture

- **Framework**: [Astro 5](https://astro.build/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animation**: [Motion](https://motion.dev/) (React islands with selective hydration)
- **Smooth Inertia**: [Lenis](https://lenis.darkroom.engineering/)
- **Bilingual**: Instant English & Bahasa Indonesia reactive localization

## Design System

- **3 Semantic Colors**: Deep Soil Brown (`#1C1814`), Warm Off-White (`#F7F5EE`), Straw Gold Accent (`#C89B3C`)
- **2 Fonts**: Lora (Editorial Serif) & Plus Jakarta Sans (Body)
- **Performance**: Zero animated CSS filters, 100svh pinned scrollytelling container, optimized WebP imagery, unmounted off-screen elements.

## Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
